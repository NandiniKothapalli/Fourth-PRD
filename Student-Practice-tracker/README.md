Student Practice Tracker
Project Description

Student Practice Tracker is a simple Java console application used to track a student's Java practice progress.

It stores:

Student Name
Course Name
Completed Topics
Solved Questions
Features
View student details
View current progress
Add completed topics
Add solved questions
Exit the application
